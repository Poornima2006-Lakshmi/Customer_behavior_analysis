# Customer Behavior Analysis

## Overview

This project analyzes customer shopping behavior using Python, PostgreSQL, SQL, and Power BI. The goal is to uncover purchasing patterns, customer trends, and business insights through data analysis and interactive visualizations.

## Dataset

The dataset contains customer shopping information, including demographics, purchase details, product categories, and spending behavior.

## Tools & Technologies

* Python (Pandas, NumPy, Matplotlib, Seaborn)
* PostgreSQL
* SQL
* Power BI
* Jupyter Notebook

## Project Workflow

1. Load and explore the dataset using Python.
2. Clean and preprocess the data.
3. Perform Exploratory Data Analysis (EDA).
4. Store data in PostgreSQL.
5. Execute SQL queries to extract insights.
6. Build interactive Power BI dashboards.
7. Summarize findings and recommendations.

## Exploratory Data Analysis (EDA)

* Data cleaning and preprocessing
* Missing value analysis
* Customer demographic analysis
* Spending pattern analysis
* Product category trends
* Data visualization

## SQL Analysis

Performed SQL queries to:

* Analyze customer purchasing behavior
* Identify top-performing categories
* Calculate sales metrics and trends
* Generate business insights

## Power BI Dashboard

The dashboard provides:

* Customer demographics overview
* Sales and revenue trends
* Product category performance
* Interactive filters and visualizations
* Key performance indicators (KPIs)

## Key Insights

* Identified customer purchasing patterns and preferences.
* Analyzed spending behavior across different customer groups.
* Highlighted high-performing product categories.
* Generated insights to support data-driven decision-making.

## Results

The project demonstrates how Python, SQL, and Power BI can be combined to transform raw customer data into meaningful business insights and visual reports.

## How to Run

1. Clone the repository.
2. Install required Python libraries.
3. Open the Jupyter Notebook and run the analysis.
4. Execute the SQL scripts in PostgreSQL.
5. Open the Power BI dashboard file to explore visualizations.
